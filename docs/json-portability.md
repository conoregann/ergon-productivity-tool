# JSON export and import

Use **Export / import** in the authenticated sidebar to download `ergon-export.json` or select a JSON file. Imports validate locally and show counts before **Import copies** writes anything. Import adds new boards; it never replaces or merges existing boards. Importing the same file again adds another copy.

The version 1 envelope has `format: "ergon"`, `version: 1`, and six required arrays: `boards`, `columns`, `cards`, `labels`, `card_labels`, and `scheduled_sessions`. Empty collections are valid. Each row contains its database business fields, including IDs and foreign keys, but omits `owner_id`, `created_at`, `updated_at`, and the row revision `version`. Account identity, authentication credentials, and user preferences are not exported.

Exports include archived boards and cards, completion timestamps, board backgrounds, ordering positions, descriptions, priorities, label assignments, date-only deadlines, and session start/end instants. The database reads all collections in one consistent snapshot under the caller's RLS policies.

Imports generate fresh IDs and remap every relationship to the new copies, assigning ownership to the signed-in account. Creation/update timestamps and revisions are generated by the database. Archives and completion history are preserved; scheduled work never changes workflow placement or completion. All inserts and archive restoration occur in one transaction. Invalid fields, duplicate IDs/positions/label names/assignments, dangling references, cross-board relationships, and invalid intervals reject the import without partial writes. Database checks also apply when the client validation is bypassed.

Deploy `supabase/migrations/20261009000300_json_portability.sql` with the other migrations before using this UI against a live backend. Database types are generated with `npm run db:types`. Unit tests cover file validation; PostgreSQL tests cover two export/import cycles, account isolation, remapping, archived history, and rollback; browser tests cover downloads, previews, validation, errors, keyboard controls, and mobile layout.
